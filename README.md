# 🏏 IPL Data Analysis using Python

A data analysis project based on **Indian Premier League (IPL)** data using Python.
The project explores different aspects of IPL matches, teams, players, and performance through **data cleaning, analysis, and visualization**.

## 📌 Project Overview

The main objective of this project is to analyze IPL data and extract meaningful insights using Python's data analysis and visualization libraries.

The project starts with data preprocessing and gradually moves toward basic as well as more advanced analysis.

## 🛠️ Technologies & Libraries Used

* 🐍 **Python**
* 🐼 **Pandas** – Data manipulation and analysis
* 🔢 **NumPy** – Numerical operations
* 📊 **Matplotlib** – Data visualization
* 🎨 **Seaborn** – Statistical data visualization
* 📓 **Jupyter Notebook** – Development and analysis environment

## 🔍 Analysis Performed

Some of the analysis covered in the project includes:

* Team-wise performance analysis
* Total runs scored by teams
* Player performance analysis
* Match statistics
* Team and player comparisons
* Season-wise analysis
* Batting and bowling performance
* Distribution and trends in match data
* Statistical analysis using NumPy and Pandas
* Data visualization using Matplotlib and Seaborn

The project includes both **basic exploratory analysis** and **advanced analytical insights** derived from the dataset.

## 📊 Visualizations

Various charts and plots are used to understand the data better, including:

* Bar charts
* Count plots
* Line charts
* Histograms
* Box plots
* Heatmaps
* Comparative visualizations

These visualizations make it easier to identify patterns, trends, and differences in IPL performance.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/your-username/IPL-Data-Analysis.git
```

### 2. Navigate to the project folder

```bash
cd IPL-Data-Analysis
```

### 3. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Open the Jupyter Notebook

```bash
jupyter notebook
```

Then open the `.ipynb` file and run the cells.
